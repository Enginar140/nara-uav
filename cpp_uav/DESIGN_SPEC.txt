TEKNOFEST UAV v10 - DESIGN SPECIFICATION
=========================================
Reference document for implementation. Every file, class, method listed.

================================================================================
ARCHITECTURE SUMMARY
================================================================================

Command Model: ALL GUIDED mode
  - GUIDED GLOBAL: DO_REPOSITION (lat,lon,alt,airspeed) → long range nav
  - GUIDED LOCAL:  SET_POSITION_TARGET_LOCAL_NED (NED pos/vel) → fine control

NO RC Override. NO FBWA. NO PID controllers for RC.

Planning: Visibility Graph + Dubins smoothing → Waypoint Chain
  - No grid-based A*, no CostMap, no Potential Fields

Modules (10):
  core → config → infra → world_model → comm → safety → nav → mission → vision → app

struct HSSZone {
    int id;
    Position center;
    double radius;
    bool active;
    double buffer_distance = 40.0;

    double effectiveRadius() const { return radius + buffer_distance; }

    vector<Position> vertices;
    double min_altitude = 30.0;
    double max_altitude = 400.0;

namespace uav::infra

enum class EventType {
    // Safety
    SAFETY_VIOLATION, BOUNDARY_VIOLATION, HSS_VIOLATION, COLLISION_WARNING,
    // Data
    OPPONENT_UPDATED, HSS_ZONE_UPDATED, BOUNDARY_UPDATED, OWN_STATE_UPDATED,
    // Mission
    MODE_CHANGED, MODE_COMMAND_RECEIVED,
    // Comm
    MAVLINK_CONNECTED, MAVLINK_DISCONNECTED,
    HEARTBEAT_TIMEOUT, HEARTBEAT_RECOVERED,
    // Failsafe
    GPS_QUALITY_LOW, GPS_QUALITY_CRITICAL,
    BATTERY_LOW, BATTERY_CRITICAL,
    // System
    SYSTEM_STARTED, SYSTEM_STOPPING
}

struct Event {
    EventType type;
    any payload;
    uint64_t timestamp_us;
    template<T> T getPayload() const;
}

using EventHandler = function<void(const Event&)>;

class EventBus {
    EventBus(size_t max_queue = 1000);
    ~EventBus();
    uint64_t subscribe(EventType, EventHandler) → subscription_id;
    void unsubscribe(uint64_t id);
    void publish(EventType, any payload = {});
    void start();
    void stop();
private:
    dispatch thread, queue, subscribers map
}

================================================================================
DATA FLOW
================================================================================

MAVLink → MAVLinkBridge → WorldModel (setOwnState, updateOpponent, updateHSSZone)
                        → EventBus (OWN_STATE_UPDATED, OPPONENT_UPDATED, HSS_ZONE_UPDATED)
                        → FlightCommander (updateModeFromHeartbeat, handleCommandAck)

GCS STATUSTEXT → StatusTextParser → EventBus (MODE_COMMAND_RECEIVED)
                                  → MissionDirector.handleModeCommand()

Main Loop (5Hz):
    MissionDirector.tick()
        → activeMode.tick(own_state)
            → NavigationEngine.planRoute() / flyDirect() / flyLocalVelocity()
                → PathPlanner.plan()              [if route needed]
                → WaypointChain.update()           [advance waypoints]
                → SafetyGate.validatePosition()    [last check]
                → FlightCommander.flyToPosition()  [send to ArduPilot]

SafetyMonitor (20Hz thread):
    → checks boundary/HSS/collision/GPS/battery
    → publishes events to EventBus
    → Application handles failsafes (RTL)

================================================================================
EVENT HANDLERS (in Application)
================================================================================

GPS_QUALITY_CRITICAL → triggerRTL("gps_critical")
BATTERY_CRITICAL     → triggerRTL("battery_critical")
HEARTBEAT_TIMEOUT    → reconnect attempts, then triggerRTL
HEARTBEAT_RECOVERED  → reset timeout counter
HSS_ZONE_UPDATED     → nav_engine.revalidateRoute()
BOUNDARY_UPDATED     → nav_engine.revalidateRoute()
HSS_VIOLATION        → nav_engine.revalidateRoute() (will replan around new zone)
MODE_COMMAND_RECEIVED→ mission.handleModeCommand()
